# 1. Git

Git merupakan sistem kontrol versi yang diciptakan oleh Linus Torvalds. Git berfungsi untuk mencatat setiap perubahan pada file proyek yang dikerjakan secara individu maupun tim. Git menggunakan konsep distributed version control sehingga database repositori tidak hanya tersimpan pada satu lokasi. :contentReference[oaicite:1]{index=1}

## Langkah Instalasi Git

1. Download Git dari https://git-scm.com/download/win
2. Jalankan file installer.
3. Klik **Next** hingga proses instalasi selesai.
4. Pilih editor yang diinginkan (Nano atau Vim).
5. Pilih opsi agar Git dikenali oleh Command Prompt.
6. Selesaikan proses instalasi.
7. Verifikasi dengan:

```bash
git --version
```

# 2. Instalasi JDK

JDK (Java Development Kit) digunakan untuk melakukan kompilasi program Java menjadi bytecode yang dapat dijalankan oleh JRE. :contentReference[oaicite:2]{index=2}

## Langkah Instalasi

1. Download JDK dari Oracle.
2. Jalankan installer.
3. Pilih lokasi instalasi.
4. Tunggu hingga proses selesai.
5. Tambahkan variabel `JAVA_HOME`.
6. Tambahkan path JDK ke Environment Variables.

# 3. Instalasi Flutter SDK

Flutter merupakan framework open source dari Google untuk membangun aplikasi mobile, web, dan desktop menggunakan satu codebase. :contentReference[oaicite:3]{index=3}

## Persyaratan

- Windows 64-bit
- Git
- PowerShell
- Android Studio
- Flutter SDK

## Langkah Instalasi

1. Download Flutter SDK.
2. Ekstrak ke folder yang diinginkan.
3. Tambahkan `flutter/bin` ke PATH.
4. Jalankan:

```bash
flutter doctor
```

# 4. Apa Itu Flutter

Flutter ditulis menggunakan bahasa Dart dan menggunakan Skia Graphics Engine untuk menampilkan antarmuka pengguna. Flutter mendukung fitur Hot Reload yang mempercepat proses pengembangan aplikasi. :contentReference[oaicite:4]{index=4}
